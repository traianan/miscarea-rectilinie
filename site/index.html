Mișcarea rectilinie

Traiectoria este o dreaptă, deci poziția corpului se descrie printr-o singură coordonată x, măsurată pe axa Ox față de originea O. Semnul lui x arată de ce parte a originii se află corpul, iar semnul vitezei arată sensul deplasării.

Poziție, deplasare, viteză medie

MĂRIMI DE BAZĂ

Δx = x2 − x1deplasarea
Δt = t2 − t1durata
vm = ΔxΔtviteza medie

Deplasarea Δx e o mărime cu semn: pozitivă când corpul ajunge mai departe în sensul axei, negativă în sens contrar. Distanța parcursă e întotdeauna pozitivă. Unitatea de măsură a vitezei în SI este m/s; 1 m/s = 3,6 km/h.

Convertor de unități pentru viteză

× 3,6 →
← : 3,6

1 km/h = 1000 m3600 s = 13,6 m/s. Exemple: pieton ≈ 1,4 m/s, biciclist ≈ 5 m/s, automobil pe autostradă ≈ 36 m/s (130 km/h).

Mișcarea rectilinie uniformă

Mișcarea rectilinie uniformă este mișcarea pe o dreaptă în care corpul parcurge distanțe egale în intervale de timp egale, oricât de mici. Viteza este constantă, iar accelerația este nulă.

      Mișcarea rectilinie uniform variată

      Corpul se mișcă pe o dreaptă, iar viteza lui variază cu cantități egale în intervale de timp egale: accelerația este constantă și diferită de zero. Dacă viteza și accelerația au același sens, mișcarea este accelerată; dacă au sensuri opuse, este încetinită.

      Formule

      a = CONST. ≠ 0 · t₀ = 0
      a = ΔvΔt = const.accelerația · m/s²
      v = v0 + a·tlegea vitezei
      x = x0 + v0t + at22legea mișcării
      v2 = v02 + 2a·Δxecuația lui Galilei
      vm = v0 + v2viteza medie
      topr = −v0a,  dopr = v022|a|oprirea (mișcare încetinită)
